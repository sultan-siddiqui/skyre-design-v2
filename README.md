# Sky Re — Version 2

A separate, self-contained design prototype based on the supplied Sky Re brand-story benchmark. The original website in the parent folder is preserved.

Open `index.html` through a local web server. All 20 page views are available through the navigation and review dropdown. Routes use URL hashes and work on GitHub Pages.

## Publish
Upload this folder's contents (`index.html`, CSS and JS files, `assets/`, `.nojekyll`) to the repository root. Enable GitHub Pages from that branch. No build command or backend is required. Keep the assets folder and local fonts.

## Design and motion
Night #00141F; Indigo #091D3C; Gold #947B4C; Cloud #F3EAD9; Sky #87A7C6. Cairo is the approved first-pass font. English final font remains subject to the brand-guideline decision. Horizon asset and crescent geometry are derived from the supplied benchmark.

All 20 pages share the benchmark celestial starfield, depth drift and twinkle, with a falling star triggered by scrolling. Headings share the Home cream-and-gold shimmer treatment. Home uses the approved company overview, interactive capacity network, eight animated service roles and Vision 2030. About contains the full six-step symbol journey, original curved star emergence/trail/arrival burst, philosophy, six interactive dimensions, geometry, foundations and values. Partners reuses the original capacity-flow illustration. Team: equal portrait cards, hover reveals, animated profile dialog and professional/personal tabs. News listing: equal card grid. Portfolio and selected insight collections: manual, keyboard-accessible sliders. Motion respects reduced-motion preferences and can be paused in the review controls.

The Home video section reuses the exact Core Philosophy SVG pattern: 54 px tiles, sky-blue and gold crescents, 13% opacity and the same radial centre fade. The previous PNG video background is no longer displayed.
